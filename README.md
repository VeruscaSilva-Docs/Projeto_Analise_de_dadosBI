# 📊 Projeto Power BI — Análise de Dados

## 📌 Sobre o projeto

Este projeto foi desenvolvido durante o curso de **Power BI e Análise de Dados do CEDERJ**, com o objetivo de aplicar, na prática, conceitos de **tratamento, modelagem, análise e visualização de dados** utilizando o Microsoft Power BI.

A proposta foi transformar dados brutos em informações organizadas e visualmente acessíveis, permitindo uma análise mais clara dos indicadores apresentados no conjunto de dados.

## 🎯 Objetivos

* Importar e organizar dados;
* Realizar o tratamento e a limpeza das informações;
* Remover valores nulos e registros desnecessários;
* Padronizar informações;
* Estruturar relacionamentos entre tabelas;
* Criar medidas e cálculos utilizando DAX;
* Desenvolver visualizações e indicadores;
* Criar um dashboard interativo;
* Facilitar a interpretação dos dados por meio de gráficos e filtros.

## 🛠️ Ferramentas utilizadas

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* **Microsoft Excel**

## 🔄 Etapas do projeto

### 1. Importação dos dados

Os dados foram importados para o Power BI a partir de planilhas, iniciando o processo de preparação para análise.

### 2. Tratamento dos dados

Foram realizadas etapas de limpeza e transformação, incluindo:

* Remoção de linhas em branco;
* Ajuste dos cabeçalhos;
* Exclusão de colunas desnecessárias;
* Tratamento de valores nulos;
* Padronização das informações;
* Separação e organização de campos;
* Ajustes nos tipos de dados.

### 3. Modelagem

Foi estruturado o modelo de dados, estabelecendo os relacionamentos necessários entre as tabelas para permitir uma análise integrada das informações.

### 4. Criação de medidas

Foram utilizados recursos de **DAX (Data Analysis Expressions)** para criação de medidas e cálculos necessários para os indicadores do projeto.

### 5. Desenvolvimento do Dashboard

Após o tratamento e a modelagem, foram criados elementos visuais para facilitar a análise dos dados, como:

* 📈 Gráficos;
* 📊 Indicadores;
* 🔎 Filtros e segmentações;
* 📋 Tabelas;
* 📌 Cards;
* 📉 Visualizações comparativas.

## 📊 Resultado

O resultado foi um **dashboard interativo**, desenvolvido para apresentar os principais indicadores de forma organizada e permitir que o usuário explore os dados utilizando filtros e diferentes visualizações.

O projeto demonstra, na prática, o fluxo de trabalho de uma análise de dados:

**Dados brutos → Tratamento → Modelagem → DAX → Visualização → Análise**

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conhecimentos relacionados a:

* Power BI;
* Power Query;
* Modelagem de dados;
* DAX;
* Tratamento de dados;
* Criação de dashboards;
* Visualização de informações;
* Análise exploratória de dados.

## 🚀 Próximos passos

Como evolução do projeto, podem ser incorporados novos indicadores, análises comparativas, métricas em DAX e recursos de visualização para ampliar a capacidade analítica do dashboard.
